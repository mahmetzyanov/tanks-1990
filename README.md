# Tanks 1990 - Battle City Clone for Android 7.0

Классическая аркадная игра в стиле Battle City ("Tanks", Dendy/NES), адаптированная для Android 7.0.

## Особенности

- **Горизонтальная ориентация экрана**
- **Сенсорное управление**: 
  - Левая часть экрана - управление движением танка (свайпы)
  - Правая часть экрана - кнопка огня
  - Верхняя центральная область - включение/выключение звука
- **Звуковое сопровождение**:
  - Звук выстрела
  - Звук взрыва при попадании
  - Звук попадания в танк
  - Звук движения танка
  - Звук Game Over
- **Индикатор состояния звука** (ON/OFF) в верхней части экрана
- **Одиночная игра** с простым ИИ противника
- **Система уровней** - 35 оригинальных уровней из Battle City
- **Процедурная генерация** для дополнительных уровней
- **Счётчик уничтоженных врагов** (20 врагов на уровень)
- **Индикатор текущего уровня**
- **Подготовка к Bluetooth мультиплееру** (требует доработки)

## Сборка и запуск

### Требования
- Android Studio Arctic Fox или новее
- JDK 8 или новее
- Android SDK API 30
- Минимальная версия Android: 7.0 (API 24)

### Инструкция по сборке

1. Откройте проект в Android Studio
2. Дождитесь завершения синхронизации Gradle
3. Подключите устройство с Android 7.0 или запустите эмулятор
4. Нажмите Run (Shift+F10)

### Сборка через командную строку

```bash
cd Tanks1990
./gradlew assembleDebug
```

APK файл будет создан в `app/build/outputs/apk/debug/`

## Управление в игре

- **Левая половина экрана**: Свайп для определения направления движения танка
  - Свайп вверх - движение вверх
  - Свайп вниз - движение вниз
  - Свайп влево - движение влево
  - Свайп вправо - движение вправо
  
- **Правая половина экрана**: Касание для выстрела

- **Верхняя центральная область**: Касание для включения/выключения звука
  - Отображается индикатор "SOUND: ON" или "SOUND: OFF"

## Игровые элементы

- **Зелёный танк**: Игрок (спавнится внизу по центру у базы)
- **Красный танк**: Противник с простым ИИ (спавнится в трёх точках сверху)
- **Серые блоки**: Стены (# - кирпичные, @ - стальные)
- **Жёлтая точка**: Пуля
- **B**: База (орёл), которую нужно защищать

## Система уровней

Игра включает систему из 35 уровней в стиле оригинальной Battle City:

- **Уровни 1-2**: Полностью воссозданные оригинальные уровни с расстановкой стен
- **Уровни 3-35**: Процедурно генерируемые уровни с симметричными паттернами
- **Цель уровня**: Уничтожить 20 вражеских танков
- **Переход на следующий уровень**: Автоматический после уничтожения всех врагов
- **Победа в игре**: После прохождения всех 35 уровней игра начинается заново

Каждый уровень имеет уникальную расстановку препятствий:
- Кирпичные стены (#) - разрушаются выстрелами
- Стальные стены (@) - неразрушимые
- Вода (~) - непроходима для танков (планируется)
- Лес (=) - скрывает танки (планируется)

## Технические детали

- Игра использует SurfaceView для рендеринга
- Частота обновления: ~60 FPS
- Разрешение адаптируется под экран устройства
- Оптимизирована для производительности на слабых устройствах
- Звуковая система использует SoundPool для низкой задержки воспроизведения
- Поддерживается Android 7.0+ (API 24+)
- Звуковые файлы хранятся в res/raw/ и загружаются при старте игры
